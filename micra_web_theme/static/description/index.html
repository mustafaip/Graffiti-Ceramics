Frequently Asked Questions

Common questions buyers usually ask before installation.

Does this theme work on both Community and Enterprise?

Yes! Micra Web Theme is designed to provide an Enterprise-grade responsive experience and home menu on Odoo 20 with complete compatibility.

How does the Dark Mode feature work?

Users can select between System (matches OS preference), Light, or Dark mode in their user preferences. The theme applies dedicated dark SCSS variables without breaking standard styles.

Does it support custom third-party modules and views?

Yes. The theme modifies primary SCSS variables, bootstrap helpers, and core view layouts cleanly, ensuring third-party modules inherit responsive styling and color schemes naturally.

Is the theme lightweight and fast?

Absolutely. Assets are cleanly compiled with Odoo's asset bundle system with zero bloated external dependencies or heavy scripts, ensuring top loading speed.
