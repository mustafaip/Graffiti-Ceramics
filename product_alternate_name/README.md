# Product Alternate Names (Odoo 20)

Sell one product under several names without duplicating the product.

**Setup**: Product form -> *Alternate Names* tab -> add name, optional code, optional sales description.

**Use**: Sales order line -> pick the **Sold As** column. Stock, price and taxes stay on the
original product; quotation, order and invoice show the alternate name.
Typing an alternate name or code in any product search also finds the product.
