# BaseLinker Connector for Odoo

Connect Odoo to 100+ sales channels via BaseLinker.

## Features

- Automatic order sync (BaseLinker → Odoo sale.order)
- Product sync with inventory data
- Customer auto-creation with address mapping
- Configurable cron jobs for automated sync
- Detailed sync logs with error tracking

## Configuration

1. Install the module
2. Go to Sales → Configuration → BaseLinker Connector
3. Create a backend and enter your BaseLinker API token
4. Configure sync settings (orders, products, pricing)
5. Click "Test Connection" to verify
6. Enable cron jobs for automatic sync

## Requirements

- Odoo 19.0 (Community or Enterprise)
- BaseLinker account with API access
- Sale module installed
